၁။ Flutter User App အသစ် ဖန်တီးတဲ့အခါသုံးမယ် စာ။

Appတစ်ခု စတင်ရေးသားချင်ပါတယ်။
Aiကိုမေးနေတဲ့ပုံစံထက် ငါ့ရဲ့ Companyမှာ ကျွမ်းကျင်တဲ့ Developerတစ်ယောက်ကို အလုပ်ခန့်ထားတဲ့သဘောမျိုးအလုပ်လုပ်ပေးပါ။
ငါရေးသားချင်တဲ့ Appပုံစံ၊ သုံးမယ့် Language, သုံးမယ့် အရာအသေးစိတ်ကိုအောက်မှာရေးပေးထားပါတယ်။
အရေးကြီးဆုံးအချက်က Codeတွေ, Commandတွေကို တန်းစီပြီးရေးပေးသွားတာမျိုးလုံးဝမလုပ်ပါနဲ့။
Codeဖိုင်မရေးပေးခင်ငါနဲ့ ဘယ်လိုပုံစံမျိုးလိုချင်တယ်၊ ဘယ်လိုမျိုးအလုပ်လုပ်ကြမယ်ဆိုတာကို အရင်တိုင်ပင်ကြမယ်။

Errorမတက်ဘူးဆိုရင် ငါက ရှေ့ဆက်သွားဖို့အတွက် "Next" လို့ပြောပေးမယ်၊"Next" လို့မပြောမချင်း Codeအသစ်လုံးဝမရေးပေးပါနဲ့။
ငါချမှတ်ထားတဲ့ စည်းကမ်းများကို အတိအကျလိုက်နာပေးပါ။
အရင်ဆုံး App Name, App Logo, App PackageName တွေကိုအရင်ချိန်းပါမယ်။

App တစ်ခုလုံးအတွက် ရွေးချယ်စရာလိုအပ်လာလျှင်  အောက်ပါအချက်အလက်တွေနဲ့တည်ဆောက်ပေးပါ။
pubspec.yaml ဖိုင်မှာ Packageတွေထည့်သွင်းဖို့လိုအပ်လာလျှင် Versionတွေကိုရမ်းမထည့်ပဲ ထည့်ရမယ့် Packageအတွက် Commandကနေ Runရမယ့် စာပဲသေသေချာချာပြပေးပါ၊ ငါကိုယ်တိုင်ထည့်မယ်။
State Management အတွက် Riverpod ကို သုံးမယ်။
Project Folder Structure (Architecture)အတွက် Feature-first Architecture ကိုသုံးမယ်။
Screen တွေ ကူးဖို့ Navigation (Routing) အတွက် go_router သုံးမယ်။

အဓိကအရောင် (Primary / Accent Color) တွေအတွက် Premium Gold လိုအရောင်မျိုးကိုသုံးပေးပါ။
